Format Ekspor Dokumen

Pilih format dokumen resmi untuk pelaporan operasional RPHU Modern

Spreadsheet Microsoft Excel (.xls) Format Resmi

Dokumen spreadsheet terformat dengan Kop Surat RPHU Modern, styling warna terstandar, indikator susut, dan lembar verifikasi audit.

• Kop Surat Resmi RPHU • Alert Susut > 3% • Tanda Tangan 3 Pejabat
Tabel Data CSV (.csv) UTF-8 · Delimiter Titik-Koma

Format data tabel terstandarisasi dengan pemisah titik-koma, blok metadata 4-kolom presisi, dan indikator status mutu terformat.

• Kompatibel Excel/SPSS/Python • Format Angka Rupiah • 21 Kolom Data Presisi
Cetak / Ekspor PDF Resmi

Format A4 Landscape siap cetak atau simpan sebagai dokumen PDF resmi.

Format .xls untuk laporan visual manajemen, format .csv untuk interoperabilitas data.
